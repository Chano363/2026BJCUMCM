## 五、逐题深度评估

### A 题　药材的烘干问题

**问题结构**
1. 预热平衡阶段温度场与水分场建模（烘房环境曲线已知）
2. 全流程（预热 + 恒温干燥，2~3 天）建模，物性采用附录3 经验公式
3. 反求"各处水分浓度均 < 0.15 kg/kg"所需烘干时间
4. 考虑药材收缩（半径变化，附录4 公式）后的烘干时长

**算法特征**
- 一维圆柱非稳态热传导与水分扩散耦合方程组：

  - 温度：`ρ·c_p·∂T/∂t = (1/r)·∂/∂r( k·r·∂T/∂r )`
  - 水分：`∂C/∂t = (1/r)·∂/∂r( D·r·∂C/∂r )`

- 边界条件为第三类（对流换热 `h = 25 W/(m²·K)`、对流传质系数 `8×10⁻⁷ m/s`），`r=0` 处对称条件
- 强非线性：`D = 7×10⁻⁹·e^(−0.89/C)`；问题2/3 起 `ρ, c_p, k, D` 全部是 `C`（甚至 `T`）的函数
- 问题4 半径由 2 cm 收缩至 1.873 cm → **移动边界问题**，需坐标变换（如 `ξ = r/s(t)`）或 ALE 网格
- 求解主流路线：隐式差分 / Crank–Nicolson / 有限体积，耦合项用 Picard 迭代或 Newton 迭代

**附件情况**：环境温度 28→50.25 ℃、含湿量 0.01963→0.05025 kg/kg（241 点 / 60 s）；半径 2→1.873 cm（145 点 / 1800 s）；4 个结果模板；输出粒度（每秒 × 每 0.1 cm）明确，无歧义。

**难度 4.0/5**：物理机理清晰、公式给定，门槛在数值实现细节。

**资料丰富度 5.0/5**（附件 5.0 + 学术文献 5.0，详见第六节）：传热传质教材、食品/中药材干燥文献极其丰富，附件与文献双重充足；干燥领域有专门期刊与大量同题域论文（含中药材收缩建模）可直接引用。

**论文易写度 4.5/5**：模型建立 → 离散推导 → 求解 → 验证 → 灵敏度分析链条完整，温度/水分云图、干燥曲线、超限位置图素材充足。

**易踩的坑**
- 题面"药材水分浓度 2.55 kg/kg"是**药材干基含水率**，而附件1 的"水分浓度"是**烘房空气含湿量**（0.02~0.05 量级），两者物理含义完全不同，极易误用
- 单位 cm / m 混用；`k`、`D` 跨数个数量级，显式格式极易发散
- "烘干结束"判据应取**中心点**水分达标（中心最难干燥）

**加分方向**：网格无关性验证、质量/能量守恒校验、`h`/`D`/`k` 灵敏度分析、与 Page 等经验干燥模型对比。

### B 题　无线电干扰源的快速自动定位与清除

**问题结构**
1. 交会定位法下多边形定位区域**直径**的算法，并讨论"以直径为直径的圆能否覆盖该区域"
2. 已知一个检测点示向度，求第二个检测点的选择策略与候选区域
3. 机器狗自主搜索定位并清除 10~16 个全向干扰源，需模拟器演练 + 3 次正式测试
4. 目标区域混入定向干扰源（覆盖 ±90°），条件同上

**算法特征**
- 问题1：计算几何。含 ±1° 误差的两条方向线围成凸四边形 → **凸包 + 旋转卡壳**求多边形直径；覆盖性讨论需构造/证明反例
- 问题2：以定位区域面积或直径为目标的**实验设计/最优化选点**，需分析退化情形（示向线近平行、交点在区外）
- 问题3：**带信息增益的覆盖路径规划**。20 个互异频道、有效接收半径 1000~1500 m；可用概率栅格 + 贝叶斯更新 + 贪心最大化信息增益，或分区割草机路线 + 交会定位闭环；时间预算包括移动 5 m/s、频道切换 1 s/次、检测 5 s、精确定位 3 s、清除 2 s，且精测需 ≤20 m
- 问题4：定向源导致**部分可观测**（存在无信号扇区），需处理信号歧义、绕行排查与不确定区域重访

**附件情况**：官方资料相当丰富——模拟器使用说明与 HTTP + JSON 通信协议共 315 段、15 张表；但**没有数据表**，成绩完全依赖模拟器实跑与导出日志。

**难度 4.5/5（五题最高）**：数学部分中上，真正门槛在工程实现与时间预算——测试窗口 25 分钟、程序运行上限 20 分钟（须在窗口开始 5 分钟内调用 `/enter`）、正式测试仅 3 次机会，且题目要求 2026-09-13 15:30 前完成正式测试。

**资料丰富度 3.5/5**（附件 3.5 + 学术文献 3.5，详见第六节）：官方材料充足，但"机器狗搜索无线电干扰源"缺少直接可引文献，需迁移移动机器人目标搜索、频谱监测、AOA/TDOA 定位文献。

**论文易写度 3.0/5**：统计指标天然量化（清除比例、平均定位清除时间、程序运行时间）、演练对比数据充足；短板是策略描述易写成工程日志，必须补足几何推导、策略复杂度与失效场景分析，否则数学含量不足。

**风险提示**：该题是五题中风险最高的一题——编程能力不足或时间安排失当会直接损失大块分数。

### C 题　微网与外部电网电力调控策略

**问题结构**
1. 电价与负载每日相同、给定光伏预测下的日前计划购电策略
2. 电价相同、负载与光伏逐时变化，含 5 倍紧急购电惩罚
3. 每日 0:00/6:00/12:00/18:00 获得 24 h 光伏预报，可滚动调整；违约价 50%、超计划价 1.5 倍
4. 电价实时波动下的策略重建（重算问题2 与问题3）

**算法特征**
- 问题1：单日 **线性规划**，144 个 10 min 时段；约束含功率平衡、SOC 递推、充放电功率上限、首末 SOC 相等、微网供电量不低于负载
- 问题2：**LP + 紧急购电松弛变量**，注意计划购电费与紧急购电费的计费口径分离
- 问题3：**滚动时域优化（MPC）/ 两阶段规划**；违约与超额采用分段线性成本（可用 0-1 变量 MILP 或绝对值线性化）
- 问题4：**随机规划 / 场景法 / 鲁棒优化**（也可用强化学习作为加分项）
- 工具：`scipy.linprog`、`PuLP`、`Gurobi`（有免费学术版）均可高效求解

**储能参数（附录1）**：最大容量 12000 kWh、最大充放电功率 5000 kW、SOC 限定 1200~10800 kWh、充放电效率 90%、2025-01-01 0:00 初始电量 6000 kWh。

**附件情况**：附件1~4 共约 13 万单元格、10 min 粒度全年数据，口径清晰；附件5 提供 5 个结果模板，输出格式明确。

**难度 2.5/5**：建模框架成熟，无冷门技巧；难点是把罚金、违约、多时点调整等**文字规则准确转成线性约束**，以及大数据批处理效率。

**资料丰富度 5/5**：微网经济调度、需求响应、MPC 文献海量，附件数据最完整。

**论文易写度 5/5（五题最高）**：可写 LP/MILP 模型推导、KKT 条件与经济含义解释、MPC 滚动机制、灵敏度分析（储能容量/效率/电价波动幅度）、策略对比（有/无储能、日前/滚动、固定/波动电价）。图表天然丰富：负荷-光伏-电价三线图、SOC 轨迹、充放电热力图、费用对比柱状图。

**注意事项**：题目要求从 2025-02-01 起算，1 月数据可用于初始化与预热；数据量大，建议预转 `parquet`/`npy` 并使用向量化读取。

### D 题　时频冲突检测与消解

**问题结构**
1. 对 150 个用频计划做时频冲突检测并统计
2. 冲突消解（一个计划只能调一个参数或撤销），统计保留/调整/撤销数量
3. 不限制平移幅度，求在无冲突解上**最多还能安排多少 C 类计划**
4. 允许 C 类计划调整间隔时长（±10Δt）后重新消解

**算法特征**
- 问题1：周期占用展开（首次时间区间 + 间隔 × 次数）→ 区间相交判定 → 构建**冲突图**（顶点 = 计划，边 = 时频双交叠）；`O(n²) = 150²` 完全可枚举
- 问题2：**带惩罚的最大独立集 / 图着色变体**；频段与时间平移幅度分别 ≤ 10Δf、5Δt；目标为分层多目标——最少撤销 > 少调整 > 保优先级（A > B > C）> 最小调整幅度，建议字典序加权 MILP 或分层求解
- 问题3：**最大可行集 / 装箱问题**，关键在于给出**理论上界论证**（资源占用率、区间图团数上界），这是拉开档次的核心
- 问题4：允许调整间隔时长，搜索空间扩大 → MILP / 约束满足（CSP）+ 局部搜索或模拟退火
- 工具：`PuLP`/`Gurobi` 处理 150 变量 MILP 无压力；`networkx` 做图论分析

**附件情况**：附件1 共 150 个计划、字段规范（频段区间 [80,90)、时间区间 [35,40)、间隔时长 60、使用次数 3 等）；100 个离散频段，规模友好；附件2 含 4 个结果模板。

**难度 3.5/5**：编码量五题最小、问题1 易得分；难在**多目标优先级的量化建模**与问题3 的上界证明——做严谨难，但做出来结论硬（可宣称最优或给出对偶界）。

**资料丰富度 4.3/5**（附件 4.0 + 学术文献 4.5，详见第六节）："时频冲突消解"直接文献少，但可迁移经典的**频率指配问题（FAP，图着色）**与区间图调度理论，文献体量大、方法成熟。

**论文易写度 3.5/5**：模型推导漂亮（可写冲突图的区间图性质、最大独立集与团覆盖的对偶关系）；但题目只给 1 张统计表 + 4 个 xlsx，**正文可视化需自行设计**（冲突图/甘特图、时频占用矩阵热力图、消解前后对比），需要额外投入。

### E 题　SEM 广告投放策略

**问题结构**
1. 从创意、关键词管理、出价策略、投放时间等角度分析 2025 年投放策略合理性，并研究效益与时间规律、假日效应
2. 按成本-效益将关键词分为黄金词/重点词/潜力词/问题词/无效词五类
3. 在预算约束下给出各推广单元与关联关键词的投放模型，并输出 2/1–8 与 8/1–8 每日最优策略
4. 2026 年 9/11–9/17 每日最优策略，并估计竞价、展现量、展现位、点击量、浏览量、注册量的期望范围

**算法特征**
- 问题1：描述性统计 + 时间序列分析（效益-时间规律、假日效应）+ 相关性/多元回归 + 方案/推广单元/创意分层对比，构建 AE 与转化漏斗指标
- 问题2：**成本-效益双指标聚类**（K-means / GMM / 分位数阈值矩阵），可用消费额与点击量/浏览量/平均访问时长/跳出率构造综合 ROI 得分后做四象限划分；需先处理零成本零效益样本
- 问题3：预算约束下的关键词组合选择 → **背包 / 0-1 整数规划**，多目标（低成本 + 高效益 + 不超预算），并叠加同推广单元内的关联约束
- 问题4：不确定性量化 → 时间序列预测（SARIMA / Prophet / XGBoost）+ **蒙特卡洛 / 自助法**给出各指标的期望区间，再做随机或鲁棒优化
- 工具：`pandas / scikit-learn / statsmodels` + `PuLP`，算法风险低

**附件情况**：附件1 Sheet1 投放记录 2627 条 × 10 字段、Sheet2 新注册数 365 天、Sheet3 关键词统计 2227 条 × 9 字段；附件2 含 3 个结果模板。

**难度 2.5/5**：无复杂数学门槛，但有两个"软坑"需提前决策。

**资料丰富度 4.3/5**（附件 4.0 + 学术文献 4.5，详见第六节）：SEM 与广告优化文献多，附件字段说明齐全；关键词组合优化、竞价与预算分配方向均有顶刊论文和最新综述可引。

**论文易写度 3.5/5**：容易写、容易画（漏斗图、四象限散点、预算分配堆叠图、预测区间带），但**容易写成数据描述报告而缺乏模型深度**；高分需靠指标体系严谨推导、整数规划模型与求解质量对比、不确定性量化、以及策略优越性的量化验证。

**必须提前决策的两个问题**
1. **"效益"未定义**：题面未给出效益口径，需自行建立合理且自洽的指标体系（注册量 / 转化率 / 浏览量加权等），这是评分分歧点，建议在论文中明确说明并做稳健性检验。
2. **附件与题面不一致**：题面称"6000 多个关键词"，但附件实际仅 **1884 个唯一关键词 / 2227 条记录**；且关键词字段被匿名化为纯数字（如 `9`、`283`），无法开展语义层面的"关键词管理与运用""创意质量"分析，只能退化为按方案/推广单元做代理分析，需在论文中说明局限。

## 七、选题建议

| 团队画像 / 目标 | 推荐题目 | 理由 |
|---|---|---|
| 求稳、希望高效完成论文 | **C** | 建模成熟、附件最丰富、结论最稳，容错率最高 |
| 数学功底扎实、想冲高奖 | **A** | 机理清晰 + 数值方法可深挖（非线性耦合、移动边界），论文含金量高且好写 |
| 编程与算法能力强、时间充裕 | **B** | 天花板最高，但必须尽早跑完正式测试，风险最大 |
| 想给出"最优/有界"的硬结论 | **D** | 规模小可求最优或给出界，但需自补可视化与多目标论证 |
| 数据挖掘 / 统计方向团队 | **E** | 门槛最低，但必须先解决"效益定义"与附件口径问题 |

**综合结论**

- 论文易写度排序：**C > A > D > E > B**
- 数学深度排序：**A ≈ D > C > B > E**
- 资料丰富度排序（附件 + 文献）：**A = C > D = E > B**
- 学术文献可得性排序：**A = C > D = E > B**
- 工程实现量排序：**B ≫ A ≈ C ≈ E > D**
- 风险由低到高：**C < E < D < A < B**

**不同团队的信息获取策略**

| 情况 | 建议 |
|---|---|
| 附件数据够用、不想花时间查文献 | A、C（附件已自带全部参数与公式） |
| 需要文献支撑建模合理性 | A、C、E（三题均可找到近乎同构的论文直接引用） |
| 想靠"方法创新"拿高分 | B、D（同题域文献少 = 创新空间大，但引用要自己搭桥） |
| 担心查不到资料卡住 | 避开 B（必须跨域拼三支文献，且真实成绩还取决于模拟器实跑） |

> 一句话建议：**时间充裕选 A，求稳选 C，编程强且能立即开跑模拟器才选 B。**
